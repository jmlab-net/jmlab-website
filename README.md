# Personal Website

Built with [Astro](https://astro.build), automated with AI.

## Stack
- **Framework**: Astro (static output → GitHub Pages)
- **Styling**: Tailwind CSS
- **Content**: Markdown via Astro Content Collections
- **Automation**: n8n + Ollama + Stable Diffusion (Unraid)
- **Development**: Claude Code (build) + Cowork (content)
- **Source**: Gitea (local) → GitHub (deployment)

## Development
```bash
npm install
npm run dev        # Start dev server at localhost:4321
npm run build      # Build for production
npm run preview    # Preview production build
```
